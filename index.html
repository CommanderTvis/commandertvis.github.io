Projects

KMath

Active co-maintainer, 2020–2022
A modular Kotlin Multiplatform library for mathematics and scientific computing. My contributions include dynamic compilation of mathematical expressions to JVM bytecode, JavaScript, and WebAssembly; constant folding and primitive-type specialization; ND4J and EJML integrations; and Jupyter support. I also maintained build infrastructure, CI, documentation, and benchmarks.
In recent years, I contribute occasionally by request. In September 2026, I added function-call support to the expression compilers and switched generated JVM classes to hidden classes.

Publications

Compilation of mathematical expressions in Kotlin

arXiv preprint, February 2021
Interpreting mathematical expressions at runtime is a standard task in scientific software engineering. This article is dedicated to a middle-ground solution implemented in the KMath library, which uses the Kotlin object builder DSL and its own algebraic abstractions to generate an AST for mathematical operations. This AST is then compiled just-in-time to generate JVM bytecode.
